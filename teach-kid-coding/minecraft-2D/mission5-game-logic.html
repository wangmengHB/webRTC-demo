What is Collision?
💥

In games, a collision is when two things touch or overlap. We detect it by checking if their rectangular areas overlap.

Two rectangles collide when: they overlap on both the X axis AND the Y axis at the same time. The function below returns true if they touch!

📦 AABB! This is called "Axis-Aligned Bounding Box" collision — the most common collision method in 2D games. Minecraft uses it for every block!

Add a Wall to Block the Player
🧱

Now let's add a wall the player can't walk through! We check if the player's new position would collide with the wall, and only allow the move if it doesn't.

This is how Minecraft stops you from walking through blocks!

🕹️ Predictive collision! We check the future position before moving. If it would collide, we cancel the move. This is called "predictive" or "speculative" collision.
