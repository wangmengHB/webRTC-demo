Numbers as Block Types
🔢

Game designers store the world in a map — a grid of numbers where each number means a different block type.

0 = sky, 1 = grass, 2 = dirt, 3 = stone, 4 = gold

We read the number and pick the right color. This is called a switch statement — it switches color based on the block type!

🗺️ Real game fact! Super Mario Bros stores its levels exactly this way — each tile in the level is a number in a big grid!

2
The Level Map Array
📋

Now we store a whole level in a 2D array — an array of arrays! Each inner array is one row. Each number in that row is one block.

We loop through every row and column, read the number, and draw the right block. It's like reading graph paper!

✏️ Designer's trick! Game designers literally draw maps on graph paper first, then translate the squares into numbers. Try it!

Add More Block Types
🧱

Let's add more block types: water (5), sand (6), lava (7), and wood (8)! The more block types we have, the richer our world can be.

Just add more case lines to the switch statement and new numbers to the map!

🌋 Biomes! Minecraft has 60+ biomes, each with their own block types — snow, jungle wood, coral, ice. They all work exactly like this!
